## The entry

> Your lucky numbers are 404, 500, and the story points your manager just invented.

A fortune-cookie line for a software engineer: the classic "your lucky numbers" opener, with HTTP error codes as the lucky numbers and the punchline landing on the story points a manager just invented.

## How it works

`main.py` (Python standard library only) writes the line to `/output/entry.txt`.

Run it with:

```sh
python3 main.py
```
